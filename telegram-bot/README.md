# Telegram-бот «Планы» (aiogram 3)

Чистый Telegram-бот на Python + aiogram 3. Никакого веб-интерфейса —
только бот, который хранит планы пользователей в персональных SQLite
базах данных.

## 🩹 Что было исправлено (важно прочитать перед обновлением)

   (`set_my_commands`) содержал команды с заглавными буквами

   команд только строчные латинские буквы, цифры и `_`, поэтому при

   с необработанным исключением ещё до старта polling'а. Теперь команды
   в меню — строчные (`myplans`, `newplan`, `everyn`, ...), а сам вызов
   обёрнут в `try/except`, чтобы даже гипотетическая будущая ошибка
   Telegram не роняла весь бот. Команды `/NewPlan`, `/MyPlans`, `/everyN`
   по-прежнему работают (регистр не важен при вводе) — это не менялось.
2. **`setup.sh` падал на первом же шаге.** Скрипт пытался скопировать

   вообще — из-за `set -e` установка прерывалась, не доходя даже до

## ✨ Что нового: уведомления

Бот теперь умеет сам писать пользователю:

- **Утренняя сводка** — что запланировано **на сегодня** (по умолчанию в 08:00).
- **Вечерняя сводка** — что запланировано **на завтра** (по умолчанию в 20:00).
  Включаются/выключаются и настраиваются по отдельности командой **`/notify`**.
- **Напоминание за N времени до конкретной задачи**, например:
  "⏰ Через 1 час у тебя задача «Сон»!".
  - Время напоминания задаётся **при создании задачи** (`/NewPlan` и `/everyN`),
    сразу после описания — можно выбрать кнопкой (15 мин / 30 мин / 1 час /
    2 часа / 1 день / без напоминания) или написать свой вариант, например
    «за 45 минут».
  - Напоминание можно **поменять позже**: открой задачу через `/MyPlans` →
    выбери день → нажми на задачу, в подробном описании внизу будет кнопка
    **«⏰ Изменить время оповещения»**.
  - Напоминание доступно только для задач с указанным временем начала
    (иначе не от чего отсчитывать «за сколько»).

Часовой пояс, по которому считается время утренней/вечерней сводки и
напоминаний, задаётся в `.env` переменной `TIMEZONE` (по умолчанию
`Europe/Moscow`).

Технически уведомления реализованы фоновой задачей (`services/notifier.py`),
которая запускается вместе с ботом и каждые `NOTIFIER_POLL_INTERVAL` секунд
(по умолчанию 30) проверяет базы всех пользователей.

## Возможности

- `/start` — приветствие и список команд.
- `/MyPlans` — показывает планы на ближайшие 7 дней (кнопками, начиная с
  сегодняшнего дня). Можно просто написать дату («19.10», «в четверг»,
  «на следующей неделе в четверг», «через 3 дня» и т.д.) — бот откроет
  планы на этот день.
- Нажатие на конкретный план показывает подробное описание
  (или «Описание отсутствует»), текущие настройки напоминания, а также
  напоминание `Успей закончить "<предыдущая задача>"!!`, если перед ней в
  этот день есть другая задача. Кнопки «Изменить время оповещения» и
  «Назад».
- `/NewPlan` — добавление разовой задачи: дата, время начала (можно
  пропустить), время окончания (можно пропустить), название, описание и
  (если указано время начала) — за сколько напомнить.
- `/everyN` — добавление повторяющейся задачи (кнопки или фразы вроде
  «каждый день», «каждые 3 дня», «по понедельникам и средам», «каждый
  месяц 15 числа», «каждый год 1 января») + настройка напоминания.
- `/notify` — настройка утренней/вечерней сводки (время и вкл/выкл).
- `/database` — присылает файл своей базы данных (.db).

## Хранение данных

У каждого пользователя — своя SQLite база в папке `PlanesUser/`:

```
PlanesUser/
  ka1d3en.db       # если есть username
  123456789.db     # если username нет — используется telegram id
  _index.json      # служебный файл: соответствие telegram_id -> файл базы
```

При первом обращении автоматически создаются нужные таблицы; при
обновлении бота на уже существующих базах недостающие колонки
(`reminder_minutes`, `reminder_sent`, `last_reminder_date`,
таблица `user_settings`) добавляются автоматически — ничего вручную
мигрировать не нужно, старые данные не теряются.

### Структура таблиц

- `user_meta(telegram_id, username, first_name, created_at, last_checked)`
- `plans(id, plan_date, time_start, time_end, title, description, reminder_minutes, reminder_sent)`
- `recurring_rules(id, title, description, time_start, time_end, start_date, rule_type, rule_value, created_at, reminder_minutes, last_reminder_date)`
- `user_settings(id=1, morning_enabled, morning_time, evening_enabled, evening_time, last_morning_sent, last_evening_sent)`

## Установка и запуск на сервере

```bash
# 1. Скопируй папку telegram-bot на сервер и зайди в неё
cd telegram-bot

# 2. Запусти установку (создаст venv/ и PlanesUser/, поставит зависимости)
chmod +x setup.sh
./setup.sh

# 3. Впиши токен бота в файл .env (BOT_TOKEN=...), при желании поменяй TIMEZONE
nano .env

# 4. Запусти бота
./venv/bin/python bot.py
```

Если бот у тебя уже установлен — просто замени все файлы из этого архива
в папке `telegram-bot` на сервере (включая новые `services/`,
`database/settings_repo.py`, `utils/clock.py`, `utils/reminder_utils.py`,
`.env.example`) и перезапусти бота. Существующие базы данных пользователей
в `PlanesUser/` трогать не нужно — они обновятся автоматически.

### Запуск как systemd-сервис (опционально)

```ini
[Unit]
Description=Telegram Plans Bot
After=network.target

[Service]
WorkingDirectory=/путь/до/telegram-bot
ExecStart=/путь/до/telegram-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now plans-bot
```
